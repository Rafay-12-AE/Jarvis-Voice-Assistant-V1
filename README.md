# Jarvis Voice Assistant (V1)

A terminal-based Python voice assistant establishing functional audio input/output and local command execution.

## 🚀 Status: V1 Baseline
- Speech-to-text input handling and voice command parsing.
- Direct terminal execution model for local system tasks.

## 🚧 Roadmap (V2 Development)
- Integration of LLM / AI decision-making logic for natural conversation.
- Multi-branch command routing and hardware telemetry integration.
